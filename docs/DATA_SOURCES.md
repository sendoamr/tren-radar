# Fuentes

| Fuente | Uso | Estado inicial | Formato |
|---|---|---|---|
| Renfe Data | posiciones, viajes e incidencias disponibles | no configurada | JSON, PB y GTFS-RT según dataset |
| NAP España | horarios programados | importación manual pendiente | GTFS ZIP |
| ADIF estado de la red | incidencias/obras públicas | conector pendiente | publicación web; validar condiciones y estabilidad |

Nunca se debe marcar una fuente como disponible solo porque su URL responda. Debe validarse esquema, cobertura y frescura.
